Can a connectome-based circuit react to a looming object?

I built a simplified spiking-neuron simulation from the male fruit fly central nervous system connectome and connected an OpenCV motion detector to a small escape-circuit simulation. The demo tests whether looming visual input can trigger the simulated giant fiber and an on-screen takeoff response.

Experiment and comparison

The model uses a leaky integrate-and-fire network and a 12,510-neuron circuit subset carved from MaleCNS v1.0. The demo turns outward optical flow from an approaching object into input for looming-sensitive neurons. I then ran the same bundled clip with intact wiring and with each source neuron's outgoing connections shuffled among random targets while preserving its weights.

Reproduce the demo

Clone the repository, install its pinned packages, then run both configurations:

python -m pip install -r requirements.txt
python swat.py --source looming-test.mp4 --headless --wiring intact
python swat.py --source looming-test.mp4 --headless --wiring shuffled

The circuit and checked metadata needed for the demo are included. Rebuilding from all connectome tables is a separate, larger-data workflow documented in the repository README.

Limitations

  • The neuron model simplifies biological dynamics and transmitter signs; it is not a detailed physiological model.
  • The input is hand-designed optical-flow processing and a synthetic test clip, not a calibrated visual pathway.
  • One clip and one shuffled control are a demonstration, not a statistical experiment or biological validation.
  • The connectome source and model paper are credited in the repository README.
